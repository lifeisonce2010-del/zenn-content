## 「またこの作業か」を、なくす

動画編集をしていると、同じ作業が何度も出てきます。

素材を読み込んで、頭とお尻の要らない部分を切って、テロップの体裁を揃えて、BGMを敷いて、いつもの設定で書き出す。1本あたりは大したことがなくても、週に5本、10本と積み上がると、じわじわ時間を持っていかれます。

この本は、**その繰り返しをAIに任せる**ための本です。

具体的には、Claude Code というAIアシスタントに日本語で指示を出すと、Premiere Pro が実際に動きます。

```
V1の3つ目のクリップを5秒地点で分割して、後半を削除して
```

こう打つだけで、タイムラインが変わります。マウスは触りません。

## この本で作れるようになるもの

最終的に、次のことができる状態を目指します。

- 素材フォルダを指定して、Premiere に一括で読み込ませる
- まとめて効く指示で、カット作業をひとまとめに片づける
- テロップのスタイルを揃えて流し込む
- BGM を敷いて、音量バランスを整える
- いつもの書き出し設定でレンダリングし、指定フォルダに出力する
- これらを組み合わせた「自分専用の定型ワークフロー」を作る

いちばん価値があるのは最後の項目です。**自分の編集の型をAIに覚えさせる**と、毎回同じ指示を打ち直す必要すらなくなります。

## この本の立ち位置

正直にお伝えしておきたいことが3つあります。

**1. Adobe公式の機能ではありません**

使うのは有志が開発したオープンソースのツールです。Adobeのアップデートで動かなくなる可能性があります。本書ではその前提でのリスク管理も扱います。

**2. 万能ではありません**

AIは「感覚」を持ちません。テンポの良し悪しや、どのカットを残すかといった判断は、まだ人間の仕事です。この本が扱うのは、**判断のいらない作業を引き剥がす**ことです。

**3. すべて実機で検証しています**

この本に載っている手順・エラー・出力は、すべて実際に動かして確認したものです。「たぶんこうなるはず」は書いていません。うまくいかなかった部分は、うまくいかなかったと書いています。

## 想定している読者

- Premiere Pro を日常的に使っている
- プログラミングの経験はない、または「黒い画面」に苦手意識がある
- 同じ作業の繰り返しに時間を取られている自覚がある

**コードは1行も書きません。** 打ち込むのは、この本に載っているコマンドをコピペするのと、あとは日本語の指示だけです。

## 動作環境

本書が検証した環境です。

| 項目 | 内容 |
| --- | --- |
| OS | Windows 11 |
| Premiere Pro | 2023以降（検証は26.0） |
| Node.js | v18以上（検証はv24.14.1） |
| Git | 2.x（検証は2.54.0） |
| Claude Code | v2.1.143 |
| 契約 | Claude の有料プラン（Pro / Max） |

:::message
macOS に対応したツールも存在します（第4章で触れます）が、本書の手順は Windows を前提に書いています。
:::

## 読み進め方

第1章から第6章までが導入と基礎です。ここは順番に読んでください。**特に第5章の「起動順」は、飛ばすと確実につまずきます。**

第7章以降は、やりたい作業から拾い読みして構いません。第14章のトラブルシューティングは、困ったときに戻ってくる辞書として使ってください。

第16章には、そのままコピーして使える指示文のテンプレートを置いています。
